Technical deep dive

Ghostprint — implementation detail

USB iOS audit CLI: libimobiledevice backups, MVT IOC scanning, profile/app heuristics, Markdown/JSON reports.

Scope: Operators and developers. Everyday guide: plain dossier.

Architecture

  • libimobiledevice — pairing, device info, idevicebackup2 backups
  • MVT — Amnesty Mobile Verification Toolkit IOC matching on backup artefacts
  • Profile / app modules — configuration profile extraction and name-based heuristics
  • Reporting — human Markdown + machine JSON

Host setup (Ubuntu/Debian)

sudo apt update
sudo apt install -y libimobiledevice-utils usbmuxd python3-pip python3-venv git

git clone https://github.com/vectisops/ios-security-auditor.git
cd ios-security-auditor
git checkout feature/initial-auditor
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install mvt

CLI

python auditor.py scan --output reports/
python auditor.py info
python auditor.py apps
python auditor.py profiles

Operational notes

  • Device must be unlocked and trusted
  • Full backup duration scales with data volume (often 30–90+ minutes)
  • Prefer isolated host (dedicated user, VM, or container)
  • No telemetry path in the tool; offline after dependency install
  • Works best on non-jailbroken devices; novel spyware without public IOCs may evade detection

Legal

Consensual examination only. Authorised device owner / explicit permission required.
