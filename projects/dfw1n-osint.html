Fork · Plain language

DFW1N-OSINT

A large curated collection of Australian-focused open-source intelligence (OSINT) resources for cyber professionals, investigators and ethical researchers.

Attribution:
This is a fork of DFW1N/DFW1N-OSINT created and maintained by Sacha Roussakis-Notter (DFW1N). Full credit for the curation and ongoing work belongs to the original author. Vectis Ops keeps this fork for local reference and Australian OSINT work.

What it is, in plain English

DFW1N-OSINT is a living list of public Australian data sources, tools and techniques useful for open-source investigations. It is especially useful for people working in or on Australia who need a structured starting point rather than searching from scratch every time.

Australia-centric

Government, corporate, geographic and people-search resources relevant to the Australian context.

Curated list

Organised collection rather than a single software tool.

GPL-3.0

Upstream is released under the GNU GPL v3.

Honest limits

  • This is a fork of a curated resource list, not original research by Vectis Ops.
  • Links and sources go stale; always verify against the live upstream repository.
  • Use only for lawful, ethical purposes and with proper authorisation where required.
