Ghostprint

Check if your iPhone has been hacked or secretly tracked — private, offline, and simple. Runs on your own computer. Never sends your data anywhere.

Status: Early public release. Core USB scan, backup analysis, and spyware fingerprint checks work. Written so non-technical people can follow along. Open source under MIT.

What Ghostprint does

If you worry someone has been watching your phone — reading messages, listening through the microphone, tracking location, or installing hidden software — Ghostprint looks for the digital “fingerprints” that kind of spyware often leaves behind.

Connects by USBSame idea as plugging in for a normal backup
Makes a careful copyThen examines that copy — not your live phone
Looks for spyware tracesUses Amnesty’s MVT engine for known fingerprints
Checks settings & appsFlags unknown profiles and suspicious apps

At the end you get a clear report in plain language.

Who it’s for

  • Anyone worried their phone may have been compromised
  • Journalists, activists, or people in higher-risk situations
  • People who want a private check without commercial “phone cleaner” apps
  • Technical users who need a starting point for deeper investigation
Important: This is not a magic virus scanner. It is a serious forensic-style check focused on known spyware and suspicious configurations. Brand-new spyware with no public fingerprints is hard to detect.

What it can and cannot do

It can help detect

  • Known commercial spyware (including some Pegasus-related families)
  • Unknown or unexpected configuration profiles that can control the phone
  • Apps that look suspicious based on their names
  • Basic signs that something unusual has been installed

It cannot

  • Guarantee the phone is 100% clean
  • Watch the phone in real time while you use it
  • Fix problems automatically — it investigates and reports
  • Work if the phone stays locked or you refuse to trust the computer

If Ghostprint finds something serious, the safest step is usually to erase the phone and set it up as new (without restoring from a possibly tainted backup).

Safety notes before you start

  • Only check phones you own or have clear permission to examine.
  • Use a clean computer if possible — ideally Linux, not the one you bank on.
  • Unlock the iPhone and tap Trust when asked.
  • Backups can take 30–90 minutes — leave the phone plugged in and charged.
  • Keep iOS updated — many attacks are fixed by software updates alone.

What you need

A Linux computer works best (Ubuntu, Debian, Fedora, etc.). macOS can work too.

Install system tools (Ubuntu / Debian)

sudo apt update
sudo apt install -y libimobiledevice-utils usbmuxd python3-pip python3-venv git

Set up Ghostprint

git clone https://github.com/vectisops/ios-security-auditor.git
cd ios-security-auditor
git checkout feature/initial-auditor

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install mvt

How to run a full check

  1. Unlock your iPhone and connect it with a USB cable.
  2. When the phone asks “Trust This Computer?”, tap Trust.
  3. On the computer, enter the tool folder and activate the virtual environment (you should see (.venv)).
  4. Run:
python auditor.py scan --output reports/

Ghostprint will collect device info, create a backup, scan for spyware fingerprints, check profiles and apps, then write a report into the reports/ folder.

Other simple commands

CommandWhat it does
python auditor.py infoShows phone name, iOS version, serial, etc.
python auditor.py appsLists apps and flags suspicious names
python auditor.py profilesLooks for configuration profiles in backups

Understanding the report

  • MVT / Spyware results — if it says “IOCs detected: YES”, treat it seriously.
  • Configuration profiles — anything you don’t recognise (especially MDM, Management, Remote, VPN) should be checked under Settings → General → VPN & Device Management.
  • Suspicious apps — rough warnings based on names only.
  • Recommendations — practical next steps at the end of every report.

If something looks wrong

  1. Don’t panic — many findings turn out to be nothing.
  2. Save the report.
  3. Remove unknown profiles on the phone.
  4. Change your Apple ID password from a different trusted device.
  5. Review devices signed into your Apple ID.
  6. Consider a full erase and set-up as new (do not restore from a suspect backup).
  7. High-risk users should contact a digital security specialist.

Privacy

Ghostprint never phones home. After software is installed it does not need the internet. Prefer a dedicated user account or disposable virtual machine. Delete the backup folder when finished if you want to clear sensitive copies from the computer.
