Vespera

A packaged local AI operator stack — models, tools, Control Center, and a one-click Windows installer. Built after serious time with LLMs: not just notebooks, but something almost anyone can deploy.

Status: Active lab product. Core install, UI, tools, vision, OSINT, and network modules work. Some packs (GPU face, full multi-agent SEL loop) are evolving. Personality is optional.

Purpose

Run capable AI on hardware you own. Prefer offline-first operation. Use real tools (shell, WSL, vision, recon, lab apps) with human allow/deny gates — not a locked cloud chat box. The same components can seed multi-agent SEL-style nodes (specialised roles, shared state, critic/inhibit).

What it includes

Local modelsOllama-hosted LLMs; swap tags anytime

InstallerPython + Ollama check, wizard, optional packs
90+ toolsShell, WSL root, files, GPU, network, more
VisionYOLO + local face galleries + reverse-image path
OSINTDomain/IP/user, Wayback, CT, EXIF, cases
Network labnmap/tshark via WSL, routes, TLS probes
Lab hooksHackRF helpers; Betaflight, QGC, EdgeTX, DJI launchers

Profiles (not a fixed “character product”)

  • Pure logic — no persona; tools and reasoning only
  • Role templates — engineer, OSINT analyst, field operator
  • Custom — set goal, tone, and boundaries at install time

Private companion setups stay private; they are not required to use the stack.

Relation to SEL

Vespera is the practical kit: models as brains, gated tools as actuators, logs/files as early shared state, vision/net/SDR as sensors. SEL is the multi-agent architecture research layer on top — Vespera is how you exercise those ideas on a real machine today.
