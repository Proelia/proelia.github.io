Vespera

A multi-OS local AI operator stack — models via Ollama, markdown personas, multi-agent orchestration, Control Center (Gradio) and a pure-terminal TUI, plus optional tool backends. Built to run on hardware you control — not a locked cloud chat box.

Status: Active. Multi-OS Python stack is the primary line of development. Legacy Windows PowerShell / WPF beta remains for reference. Tool packs degrade gracefully when optional backends are offline. Personality is optional.

Purpose

Run capable language models and operator tools on owner-controlled machines. Prefer offline-first operation after models are present. Expose extra capabilities only through optional local backends and operator choice — default bind addresses assume localhost.

Search Web search SearXNG or HTML fallback
Network Connectivity, DNS, routes, local listeners System tools — own / authorized networks only

Tools are optional. If a backend is down, the rest of the stack still runs.

Personas (public set)

  • Pure logic — structured analysis, minimal theatrics
  • OSINT analyst — open-source research framing
  • Operational planner — structured planning language
  • Multi-agent roles — strategist, executor, critic, synthesizer

Custom personas are plain markdown (optional YAML frontmatter for recommended models and VRAM notes). Private role libraries are not required to use the stack.

Quick start

git clone https://github.com/vectisops/Vespera.git
cd Vespera/multi_os
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m vespera scan
python -m vespera ui    # http://127.0.0.1:7860

Requires a local Ollama install. Tool setup is documented in-repo at multi_os/docs/TOOLS.md.
