Orientation

This repository is primarily a curated collection of links, tools and notes focused on Australian open-source intelligence work. It is not a single executable application; it is a living reference that the original author continues to maintain. The Vectis Ops fork exists so the material remains available for local reference and Australian-focused OSINT practice.

Typical usage

git clone https://github.com/vectisops/DFW1N-OSINT.git
cd DFW1N-OSINT
# Browse the README and category files
# Prefer the live upstream repo for the most current links
