Fork · Plain language

Shadowbroker

An open-source geospatial intelligence platform that aggregates many public OSINT feeds (aircraft, ships, satellites, seismic, conflict and more) into a single map interface.

Attribution:
This is a fork of BigBodyCobain/Shadowbroker by BigBodyCobain. All primary development credit belongs to the original author and contributors. Vectis Ops keeps this fork for local evaluation and self-hosting tests.

What it is, in plain English

Shadowbroker pulls together live and near-live public data sources and displays them on a dark-ops style map. It is intended to be self-hosted so the operator controls the instance rather than relying on a single public site.

Multi-domain feeds

Aircraft, maritime, satellite, seismic, conflict and other open feeds are brought together.

Self-hosted

Docker-oriented deployment is the common path upstream.

Open source

Upstream is released under AGPL-3.0; respect the licence when modifying or redistributing.

Honest limits

  • This is a fork, not original Vectis Ops software.
  • Data accuracy depends entirely on the public sources used by the upstream project.
  • AGPL obligations apply to network-accessible modified versions.
