Vespera — stack detail

Multi-OS local AI operator layer around Ollama: personas, multi-agent pipeline, Gradio/TUI/CLI, optional tool packs.

Scope: Engineers and operators. Non-technical overview: plain dossier.

Components

Local modelsOllama-hosted LLMs; swap tags anytime
Hardware prescanRAM / VRAM-aware quant guidance
PersonasMarkdown system prompts; nested folders
Multi-agent pipelineStrategist → Executor → Critic → Synthesizer
Control CenterGradio UI — chat, persona, model, hardware
Terminal TUITextual UI for headless use
CLIscan, status, personas, chat, multi, tools
Optional toolsMedia, voice, search, network diagnostics

Quick start (Linux)

git clone https://github.com/vectisops/Vespera.git
cd Vespera/multi_os
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
ollama serve   # if needed
python -m vespera scan
python -m vespera ui    # http://127.0.0.1:7860

CLI

python -m vespera status
python -m vespera personas
python -m vespera chat "Hello"
python -m vespera multi "Outline a local serving layout"
python -m vespera tools

Android remote client

Material 3 / Jetpack Compose thin client over LAN to host Ollama (default 11434) and optional persona sidecar. Prefer private Wi‑Fi or Tailscale; do not expose ports publicly. Debug APK via Android Studio / Gradle.

Security defaults

Localhost binds by default. Defensive network tools only. Operator remains in control of tool backends.
