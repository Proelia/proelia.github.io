Orientation

World Monitor is a substantial TypeScript-based dashboard that ingests many public data sources and presents them on a map-centric interface. The upstream repository is actively developed and has a large community. This fork is kept for local inspection and self-hosting trials under Vectis Ops.

Typical starting path

git clone https://github.com/vectisops/worldmonitor.git
cd worldmonitor
npm install
npm run dev
# Prefer upstream README for current build / deploy instructions
