AutoJob — stack detail

Personal job-search pipeline for Australia (SEQ focus): multi-source collection, local ranking against user preferences + résumé, de-duplication, and one-click apply links. Private by design.

Scope: Engineers and operators. Non-technical overview: plain dossier.

Components

FiltersLocations, titles, include/exclude keywords, salary range
RankingScores listings against preferences + optional résumé
Top-N resultsHard cap at 30 strongest matches
Local historyDe-duplication so later runs stay fresh
Apply linksOpens official job page only — never auto-submits
Company intelLight employer context with SEQ-relevant notes
SettingsAPI keys + optional one-time browser auth (local profile)
ExportSpreadsheet export of ranked results

Sources & auth

SourceNotesAuth
AdzunaPrimary free API for broader coverageAPI keys (developer.adzuna.com)
Seek (optional)Session-based when neededOne-time browser login stored locally

Quick start

git clone https://github.com/vectisops/AutoJob.git
cd AutoJob
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
playwright install chromium

# Linux extras
sudo apt install python3-tk
playwright install-deps chromium

python -m src.main

Typical workflow

  1. Settings → add free Adzuna API keys
  2. Optional: Authenticate Seek (opens browser once, profile stays local)
  3. Filters → set locations / titles / keywords / salary
  4. Optional: upload résumé (PDF or Word)
  5. Search → review Top 30 → Apply Now or Export Excel

Privacy defaults

Résumé, search preferences, job history, and browser sessions remain on the local machine. No central ranking service, no bulk data collection for third parties. Designed for a single user only.
